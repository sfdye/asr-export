ASR is migrating from Habitap to iCondo. House rules and meeting minutes will move across — but unit drawings, warranties and user guides will not, and once Habitap is discontinued, unit drawings can only be repurchased via the BCA Portal. Downloading everything by hand isn't practical — asr-export uses your own account to back up your documents first, sorted into folders. It runs entirely on your machine, and your password is never saved.

Features

What it does

It turns an evening of tapping through the app into a few minutes of copy-paste.

📄

Everything you can see

Lists every document your account sees in the app — exactly as shown for your block and unit.

📂

Sorted by category

Files land in named folders (Circulars, Manuals, Warranties…), each named after its title in the app.

⏯

Stop & resume anytime

Interrupt with Ctrl+C any time. Re-running picks up where you left off — already-downloaded files are skipped.

👀

Preview before downloading

Categories are previewed when you list them, and --dry-run shows exactly what would be saved.

🔑

Log in once

First login on a new device needs a one-time code from your email. After that, you stay logged in.

🧩

Zero dependencies

Pure Python 3 — the programming tool your computer usually already has. Nothing else to install.

Install

One-time setup

"Installing" just means copying a small tool from this website onto your computer, so that later you can start it by typing one word. Three steps — copy, open, paste — and about a minute. Pick your computer:

Step 1 · Copy

Copy the install command

Press the button. You won't see anything happen — the command is now held on your clipboard, ready to paste.

curl -fsSL https://sfdye.github.io/asr-export/install.sh | bash
Step 2 · Open

Open the Terminal

Press ⌘+Space, type Terminal, press Enter. A plain window opens — that's the Terminal. It's just a text box; nothing you paste here can break your computer.

Step 3 · Paste

Paste and press Enter

Click inside the window, press ⌘+V, then Enter. Some text scrolls by — when you see ✅ Done!, it's finished. Then open a new Terminal window (⌘+N) for the steps below.

Step 1 · Copy

Copy the download command

Press the button. You won't see anything happen — the command is now held on your clipboard, ready to paste.

cd $env:USERPROFILE\Documents; curl.exe -fsSLO https://github.com/sfdye/asr-export/raw/main/asr-export.py
Step 2 · Open

Open PowerShell

Press the ⊞ Win key, type PowerShell, press Enter. A blue window opens — that's PowerShell, Windows' version of the Terminal. It's just a text box; nothing you paste here can break your computer.

Step 3 · Paste

Paste and press Enter

Click inside the window, press Ctrl+V (or right-click), then Enter. A file named asr-export.py now sits in your Documents folder. On Windows, every command in this guide starts with python asr-export.py — and if you open a new PowerShell window, first paste cd $env:USERPROFILE\Documents again.

ℹ️ What just happened? You copied a small, safe tool from this website onto your own computer. It doesn't run by itself, changes nothing else on your machine, and only talks to Habitap — your condo's app — when you ask it to.
Step-by-step

Your backup in 5 minutes

Each step is one short command. Paste it into the Terminal, press Enter, and follow what it says.

1

Open the Terminal

Mac: press ⌘+Space, type Terminal, press Enter.  Windows: press ⊞ Win, type PowerShell, press Enter. This is where you'll paste the commands below. It looks plain, but it's just a text box — nothing can break.

2

Install the tool (once)

Follow the three steps in the Install section above — you only ever do this once. If the Terminal later says command not found, open a new Terminal window and try again.

3

Log in with your Habitap account

Type your email and Habitap password when asked. The password won't show as you type — that's normal, just type it and press Enter. The first time on a new device, it emails you a one-time code (OTP): check your inbox, type the code in, press Enter. That's it — you're logged in.

asr-export login          # Windows: python asr-export.py login
4

See what you have

This shows your document categories and how many files are in each — exactly the same set you see in the Habitap app, filtered to your block.

asr-export list           # browse categories (large ones are previewed)
5

Download everything

The tool asks which categories you want — type all for everything, or numbers like 1,3 to pick. It then shows a total and waits for you to confirm with y before anything is downloaded. Want a sneak peek first? Run the --dry-run version — it lists what would be saved without downloading.

asr-export download       # pick categories -> confirm -> download
asr-export download --dry-run  # preview only, downloads nothing
6

Find your files

Files are saved to Documents/asr-export, in a folder per category, one PDF per document. Interrupt any time with Ctrl+C — progress is saved after every file; just run asr-export download again to continue. Once done, copy the folder to a USB drive or cloud storage for safekeeping.

Privacy

Where your data goes

Everything runs locally on your machine. The tool talks to nothing except Habitap's own website and file servers, over an encrypted connection.

QuestionAnswer
Where do my files go?Straight from Habitap's servers to a folder on your computer. Nowhere else.
Is my password stored?No. It's used only to log in to Habitap over HTTPS and is never written to disk — it exists in memory only during login.
What is stored on my computer?A login session (cookie) in a private folder ~/.asr, plus small lists of already-downloaded files so re-runs can skip them.
Does anyone else get my data?No. The tool contacts only Habitap's own API and file CDN. This website is a static page — it collects nothing.
⚠️ Use your own account only, and download only what it can access, for personal archival. Downloads are deliberately paced so we don't burden Habitap's servers — please don't try to speed them up.
FAQ

Frequently asked questions

I ran login again and it did nothing.
That means you're already logged in — the tool detects a working session and exits immediately. Use login --force to re-login or switch accounts.
I see an SSL / CERTIFICATE error message.
You can ignore it — newer Python versions are stricter about certificates and the tool handles this internally. The connection is still fully verified.
My neighbour's list looks different from mine.
That's expected. The document set is exactly what your own account sees in the app, filtered by your block and unit.
Can I download just one category?
Yes: asr-export download --cat Circulars (replace with the category name you saw in list). Or everything except a category: asr-export download --not Circulars.
Where do I get help?
Ask in the residents' chat, or open an issue on the GitHub page.
